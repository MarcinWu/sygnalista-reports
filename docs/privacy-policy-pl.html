DipRadar — Polityka prywatności

Ostatnia aktualizacja: 20 maja 2026 r.

Wstęp

DipRadar to bezpłatne narzędzie edukacyjno-analityczne prezentujące wzorce techniczne i dane fundamentalne spółek giełdowych. Dbamy o Twoją prywatność i zbieramy tylko niezbędne minimum danych.

Dane zbierane przez aplikację

Anonimowy identyfikator urządzenia

Przy pierwszym uruchomieniu aplikacji lokalnie na urządzeniu generowany jest losowy 32-znakowy identyfikator. Nie zawiera on żadnych danych osobowych ani nie umożliwia identyfikacji użytkownika. Służy wyłącznie do zapobiegania zduplikowanym głosom „polub". Reinstalacja aplikacji generuje nowy identyfikator.

Preferencje lokalne

Aplikacja przechowuje na urządzeniu (nigdy nie wysyła na żaden serwer):

  • Informację o akceptacji regulaminu
  • Wybrany język interfejsu (polski lub angielski)
  • Polubione wzorce / spółki

Dane wysyłane na zewnątrz

API polubień

Po naciśnięciu „Polub" przy wzorcu aplikacja wysyła anonimowy identyfikator urządzenia i symbol spółki na nasz prywatny serwer (Cloudflare Workers) w celu zarejestrowania głosu. Te dane służą wyłącznie do zliczania polubień i deduplikacji. Żadne inne dane nie są przesyłane.

Logo spółek

Logo spółek pobierane są z publicznego serwisu favicon Google na podstawie nazwy domeny spółki (np. „apple.com" dla AAPL). W żądaniach nie są przesyłane żadne dane użytkownika.

Firebase Crashlytics

Korzystamy z Google Firebase Crashlytics do zbierania anonimowych raportów o awariach aplikacji. Pomaga to wykrywać i naprawiać błędy. Raporty mogą zawierać model urządzenia, wersję systemu, ślad stosu i stan aplikacji w momencie awarii. Nie zawierają danych osobowych. Polityka prywatności Firebase.

Firebase Analytics

Korzystamy z Google Firebase Analytics do zbierania anonimowych statystyk użytkowania (czas sesji, wyświetlane ekrany, typ urządzenia). Pomaga to nam zrozumieć sposób korzystania z aplikacji. Dane są zagregowane i nie umożliwiają identyfikacji użytkowników. Nie używamy identyfikatorów reklamowych. Polityka prywatności Firebase.

Firebase Cloud Messaging

Wykorzystujemy Firebase Cloud Messaging do wysyłki powiadomień o nowych przykładach wzorców. Otrzymujemy anonimowy token urządzenia generowany przez Google. Nie powiązujemy tokenów z jakimikolwiek danymi osobowymi.

Dane, których NIE zbieramy

  • Brak danych osobowych (imię, e-mail, telefon, lokalizacja)
  • Brak identyfikatorów reklamowych
  • Brak zewnętrznych SDK reklamowych ani śledzących
  • Brak informacji o portfelu inwestycyjnym, dochodach lub preferencjach inwestycyjnych użytkownika

Podmioty trzecie

  • Google Firebase — Crashlytics, Analytics, Cloud Messaging. Polityka Firebase.
  • GitHub — raporty dzienne pobierane są z publicznego repozytorium GitHub. Nie są wysyłane żadne dane użytkownika.
  • Cloudflare Workers — hostuje API polubień. Otrzymuje wyłącznie anonimowy identyfikator urządzenia i symbol spółki.
  • Google Favicon Service — dostarcza logo spółek. Otrzymuje wyłącznie nazwy domen.

Okres przechowywania

Polubienia i identyfikatory urządzeń na naszym serwerze są resetowane codziennie. Dane lokalne pozostają do momentu odinstalowania aplikacji lub wyczyszczenia danych aplikacji.

Prawa użytkownika (RODO)

Zgodnie z RODO masz prawo do dostępu, sprostowania, usunięcia i ograniczenia przetwarzania swoich danych. Aplikacja nie przetwarza danych osobowych w sposób, który pozwalałby na identyfikację konkretnej osoby — wszystkie zbierane dane są anonimowe.

Prywatność dzieci

Aplikacja nie jest skierowana do dzieci poniżej 13. roku życia. Nie zbieramy świadomie danych od dzieci.

Zmiany

Polityka może być od czasu do czasu aktualizowana. Zmiany będą publikowane na tej stronie wraz z datą aktualizacji.
